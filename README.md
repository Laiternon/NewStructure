# Anime Builder — мод для Minecraft Forge 1.20.1 (47.2.0+)

Чертёж аниме-построек: окно выбора, 3D-предпросмотр в GUI, призрак постройки в мире и автопостройка
из ресурсов инвентаря и сундуков/бочек/шалкеров в радиусе 16 блоков.

## Сборка .jar
**Без установки программ:** загрузите папку проекта в репозиторий на github.com (вместе со скрытой папкой `.github`),
вкладка Actions → «Build mod» → Run workflow → скачайте артефакт `animebuilder-jar` → положите .jar в `mods`
(в TLauncher должна стоять версия «Forge 1.20.1»).
**Локально:** скопируйте `gradlew`, `gradlew.bat`, `gradle/` из Forge MDK 1.20.1, JDK 17, `./gradlew build`.

## Как пользоваться
- Крафт чертежа: книга + лазурит + бумага (бесформенный). Есть во вкладке творчества «Anime Builder».
- ПКМ с чертежом — окно: категории (< >), список построек, 3D-превью (мышь — вращать, колесо — масштаб), справа материалы «есть/нужно».
- «Предпросмотр в мире»: призрак следует за прицелом. R — повернуть, Z — зафиксировать, B — построить, X — отмена. Зелёный — ресурсов хватает, красный — нет.
- «Построить здесь» — строит туда, куда вы смотрели при открытии окна.
- Творческий режим: ресурсы не тратятся. Стройка идёт постепенно (96 блоков/тик).
- Пол постройки (слой y=0) встаёт вровень с блоком, на который вы навели прицел.

## Как гарантируется, что ничего не висит и не пропадает
Постройки сделаны инструментом `tools/` (Python) и перед экспортом проходят проверку: каждый блок связан с землёй, лестницы/факелы/двери/кровати
имеют опору и обе половины, вода и лава запечатаны (не растекутся), листва `persistent` (не опадает), цветы стоят на почве.
При строительстве мод: сначала достраивает ПРИРОДНЫЙ фундамент под колоннами (бесплатно), потом ставит твёрдые блоки снизу вверх, а воду и лаву — В САМУЮ
ПОСЛЕДНЮЮ очередь; подгружает чанки; вычищает местность внутри построек; затем поправляет соединения заборов/стёкол/стен/лестниц.
Защищённые блоки и блоки с инвентарём (сундуки) пропускаются.
Траву/дорожки считает как землю, котлы с водой/лавой — как котёл.

## Свои постройки
`tools/packs/*.py` + `python tools/export_all.py` — перегенерирует JSON в `src/main/resources/data/animebuilder/structures/`.

Проект написан без доступа к Minecraft/Forge и НЕ компилировался; постройки проверены только автоматической проверкой и схематическими превью.
